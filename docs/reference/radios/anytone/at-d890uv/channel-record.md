# AT-D890UV — channel record

Combined **`0x80`-byte** channel element for Anytone AT-D890UV (`encode_D890UV` / `decode_D890UV`). Stored as two **`0x40`** halves at radio addresses derived from `D890_MAP`.

**Hub:** [README.md](README.md) · **Regions:** [memory-layout.md](memory-layout.md)

Cite: anytone-cps channel encode/decode + `Device::readChannelData` / `writeChannelData` — facts only; do not paste GPL sources.

## Geometry

| Fact             | Value                                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Combined size    | `0x80` (128) bytes                                                                                                                |
| Primary half     | `0x40` at `primaryAddr`                                                                                                           |
| Secondary half   | `0x40` at `primaryAddr + 0x40`                                                                                                    |
| Max slots        | 4000 (ChannelSet `0x200` bytes)                                                                                                   |
| Occupancy        | Bit in ChannelSet @ `0x3482a00` — not empty FF fill alone                                                                         |
| Name storage     | Studio writes `0x20` bytes at offset `0x44` (`0x44–0x63`). CPS name is `0x22` bytes (`0x44–0x65`). `0x64–0x65` are not preserved. |
| Name display cap | 16 chars (CSV / [limits.md](limits.md))                                                                                           |

## Address formula

0-based index `idx`:

```text
blockIndex    = idx / 128
indexInBlock  = idx % 128
primaryAddr   = 0x1000000 + (blockIndex * 0x80000) + (indexInBlock * 0x80)
secondaryAddr = primaryAddr + 0x40
```

Assemble decode buffer as `primary ‖ secondary`. Split encode the same way before write. See [memory-layout.md](memory-layout.md).

## ChannelSet bitmap

| Item           | Value                                                                                                                            |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Base           | `0x3482a00`                                                                                                                      |
| Size           | `0x200` bytes                                                                                                                    |
| Sense          | Bit **set** → channel present                                                                                                    |
| Indexing       | Slot `n` → byte `n // 8`, bit `n % 8`                                                                                            |
| Modelled slots | `0 … 3999` (`MAX_CHANNELS`) — Studio Write clears and re-encodes these bits only                                                 |
| High bits      | Bits `4000+` in the `0x200`-byte bitmap are **preserved** on Write (VFO-ish / RE slots; bodies not modelled as library channels) |

Empty slots (RX frequency 0 / unset) should clear the bit and skip body writes.

## Studio overlay

Each occupied modelled slot is a whole-record overlay: modelled fields and the #1273 safety defaults come from the DTO, not from whoever last occupied the slot. `encodeAtD890ChannelRecord(ch)` with no prior is `fill(0)` plus that overlay. Image encode (`encodeChannelsIntoAtD890Image`) reads `primary ‖ secondary` for each slot it will write **before** the bank zero-fill and passes that buffer as the prior. The prior is ignored when it is shorter than `0x80`, when RX BCD at `0x00–0x03` is vacant (same rule as `parseAtD890ChannelRecord`), or when every byte is `0xff` (deprecated virgin fill — do not copy `0xff` into NXDN). Stock and MM9PDY share this encoder. Sparse erase-unit RMW ([#768](https://github.com/pskillen/codeplug-studio/issues/768)) still preserves co-resident **regions** outside the channel body.

## Write defaults (unmodelled fields)

On Web Serial Write, modelled fields and the safety defaults below are a whole-record overlay from the DTO. They are not copied from the previous occupant. The [preserve list](#preserve-list) is the only intra-record copy, and only from the slot’s downloaded record when one exists. A new or vacant slot still encodes as zeros plus the projection and these defaults. Region / erase-unit RMW is unchanged.

| Field / offset                                                         | Write default   | Notes                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SMS Confirmation `0x21` bit 1                                          | **On**          | CPS default; not modelled                                                                                                                                                                                                                                                                                                                                                                              |
| Talkaround / call confirm / reverse / PTT prohibit `0x09` bits 7/6/4/5 | **Off** (`0`)   | Bit 5 is TX/PTT prohibit, unmodelled. It is not `rxOnly`.                                                                                                                                                                                                                                                                                                                                              |
| Slot Suit / Work alone / unknown `0x21` bits 4/6/7                     | `0`             | DCDM (`0x21` bits 2–3) always `0` on Write; modelled DMO/repeater clear that nibble                                                                                                                                                                                                                                                                                                                    |
| Simplex TX offset `0x04–0x07`                                          | **0**           | Do not keep a previous repeater offset on a simplex row                                                                                                                                                                                                                                                                                                                                                |
| Contact `0x13–0x17`                                                    | Current encoder | A present `txContactId` is a little-endian u32 at `0x14–0x17`, `0x13 = 0`, `wire = id − 1`. An omitted id writes five zero bytes at `0x13–0x17` (slot 0). Do not write `0x17 = 0xFF`. Decode still treats `0x17 >= 0x7F` as none. These five bytes are never copied from the prior. Supersedes investigation [i008 W20](../../../../investigations/i008-d890-channel-intra-record-rmw/01-findings.md). |
| APRS `0x35`, `0x37`, `0x38`                                            | DTO or `0`      | Omitted DTO fields stay 0. Do not preserve them from the prior.                                                                                                                                                                                                                                                                                                                                        |
| Name `0x44–0x63`                                                       | DTO name        | `encodeWideCharName(wireName, 0x20)` at `0x44`. CPS name is `0x22` bytes (`0x44–0x65`). Do not preserve `0x64–0x65`.                                                                                                                                                                                                                                                                                   |
| Bytes the CPS never writes (`0x23–0x33`, `0x6f–0x7f`) and `0x42`       | `0`             | Not on the preserve list.                                                                                                                                                                                                                                                                                                                                                                              |

### Preserve list

Copied from the downloaded slot only when the prior is present (see [Studio overlay](#studio-overlay)). Otherwise these ranges stay 0. Modelled bytes are written after the copy.

| Copy                      | What                                                              |
| ------------------------- | ----------------------------------------------------------------- |
| `0x10–0x12`               | Custom CTCSS, tone2 decode                                        |
| `0x19–0x1a`               | Squelch / PTT-ID, busy lock                                       |
| `0x1d–0x1f`               | Tone2, tone5, DTMF indices                                        |
| `0x22`                    | AES encryption index                                              |
| `0x34` bits 0, 2, 5, 6, 7 | Ranging, exclude-from-roaming, idle TX, compander, DMR CRC ignore |
| `0x36`, `0x39–0x41`       | Unmodelled APRS / encryption siblings, scrambler, R5Tone BOT/EOT  |
| `0x66–0x6e`               | NXDN                                                              |

Not copied: `0x00–0x0f` (frequencies, duplex, power, mode, tone selects, DCS, and the `0x09` flag bits); `0x13–0x17` (contact — current encoder, not the prior and not `0xffff`); `0x18`, `0x1b`, `0x1c`, `0x20`, `0x21` (radio ID, scan list, RX group, colour code, timeslot / SMS confirm / APRS RX — SMS confirm bit 1 stays On); `0x23–0x33` and `0x6f–0x7f`; `0x35`, `0x37`, `0x38`; `0x42`; `0x43` (TX colour code — the encoder already mirrors `colorCode`); `0x44–0x65` (name).

`0x34` bits 1, 3, and 4 are applied after the bit copy. Bit 3 does not clear bits 1 and 4. Those two bits still follow the DTO: bit 1 set only for digital `dmo-simplex`, bit 4 set only when `scanAdd === true`.

## Byte `0x21`

Little-endian bit numbers. Evidence: qDMR `libdmrconf` `anytone_d868uv_codeplug.cc` (`timeSlot: {0x0021, 0}`, `smsConfirm: {0x0021, 1}`, `dmrMode` bits 2–3 as the **DCDM nibble**) plus forensic `HEALTHY_CHANNEL_RECORDS` (181 occupied slots: bit 1 always set, bit 0 set on 18; **bits 2–3 always 0**, including digital repeaters). anytone-cps `Channel::encode_D890UV` tests **bit 1** for timeslot — that swap is **not** used here. Do **not** map CSV `DMR MODE` `0`/`1` onto bits 2–3: writing `1` is radio menu **DCDM/Dual TS**.

| Bit | Field                                                                   | Studio overlay                                                                 |
| --- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 0   | Time slot (`0` = TS1, `1` = TS2)                                        | Written from DTO `timeslot`                                                    |
| 1   | SMS Confirmation                                                        | Unmodelled. Write default **On**                                               |
| 2–3 | DCDM / Dual TS / TS split (`0` not DCDM, `1` Dual TS, `2`/`3` TS split) | Modelled DMO/repeater always write `0`. Radio menu items 3–4. Unmodelled DCDM. |
| 4   | Slot Suit                                                               | Unmodelled — write `0`                                                         |
| 5   | APRS RX                                                                 | Written from `Channel.aprs.receiveEnabled` when set                            |
| 6   | (unused / unknown)                                                      | Write `0`                                                                      |
| 7   | Work alone                                                              | Unmodelled — write `0`                                                         |

## Byte `0x34` bit 1 (DMO vs repeater)

CPS map of byte `0x34`, bit 0 → bit 7: ranging, DMO, exclude-from-roaming, RX only, auto scan, idle TX, compander, DMR CRC ignore. There is no data-ACK-disable flag on this byte.

| Bit | CPS field            | Studio                                                                                        |
| --- | -------------------- | --------------------------------------------------------------------------------------------- |
| 0   | Ranging              | Unmodelled. Preserved from the downloaded slot when one exists; otherwise clear.              |
| 1   | DMO vs repeater      | Set only for digital `dmo-simplex`. Digital repeater, analog, and omitted clear it.           |
| 2   | Exclude from roaming | Unmodelled. Preserved from the downloaded slot when one exists; otherwise clear.              |
| 3   | RX only              | Written from `RadioChannelDto.rxOnly`. Omitted or false clears. This is the CPS RX-only flag. |
| 4   | Auto scan            | Set only when `scanAdd === true`; otherwise clear. Not scan-list membership.                  |
| 5   | Idle TX              | Unmodelled. Preserved from the downloaded slot when one exists; otherwise clear.              |
| 6   | Compander            | Unmodelled. Preserved from the downloaded slot when one exists; otherwise clear.              |
| 7   | DMR CRC ignore       | Unmodelled. Preserved from the downloaded slot when one exists; otherwise clear.              |

`0x09` bit 5 is TX/PTT prohibit. Studio does not model it and writes it clear. It is not `rxOnly`.

CPS `DMR MODE` column `0`/`1` (DMO / Repeater) and radio menu items 1–2 map to **bit 1** — **not** to `0x21` bits 2–3. CSV `2`/`3` (DCDM) stay on the `0x21` nibble and are not modelled.

| Wire | Radio / CPS   | Forensic (CPS-written digital slots) |
| ---- | ------------- | ------------------------------------ |
| `1`  | DMO / simplex | Digital simplex: bit 1 set           |
| `0`  | Repeater      | Digital duplex: bit 1 clear          |

anytone-cps names this `dmr_mode` on `0x34` bit 1 (`1` sets the bit). Studio polarity matches CPS-written dumps: **set = DMO**. Overlay when `RadioChannelDto.dmrOperatingMode` is present (digital rows). Analog / omitted: write `0` (whole-record default).

## Power (`tx_power` in byte `0x08`)

Wire enum (2 bits) maps to CPS labels; Studio `%` ladder for **file** adapters is in [power.md](power.md). Binary adapter should map the same four steps (Low / Mid / High / Turbo) at the edge — do not invent a fifth level.

## Empty channel

`rx_frequency == 0` → treat as vacant (anytone-cps decode returns early). Clear ChannelSet bit; prefer not writing body, or write zeros consistently with the adapter policy.
