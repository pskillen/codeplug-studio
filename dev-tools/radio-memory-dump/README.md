# radio-memory-dump

Read-only serial memory dump CLI for radio protocol investigation. Not part
of the app — not built, not shipped, not imported by `src/`.

## Setup

Requires `python3.14` (or any Python ≥ 3.12).

```bash
cd dev-tools/radio-memory-dump
python3.14 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
```
