# SupportMark

Tick / half / cross / dash glyph for a `SupportState`. The glyph is `aria-hidden`; a visually hidden label ("Supported", "Partly supported", "Not supported", "Not applicable") carries the meaning. Labels live in `supportLabels.ts`.

| Prop    | Type           |
| ------- | -------------- |
| `state` | `SupportState` |

Related: [RadioSupportMatrix](RadioSupportMatrix.md), [RadioFinder](RadioFinder.md).
